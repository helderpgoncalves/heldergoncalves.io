# Projetos

## MCP para a app Stocks do macOS

Um servidor MCP que lê a base de dados local da aplicação Stocks do macOS e
devolve carteiras e cotações a qualquer modelo. Sem API paga, sem scraping:
os dados já estavam no disco.
Feito com: MCP, Swift, macOS.

## Garmin → Claude Code

Uma ponte que transforma um ciclocomputador Garmin num controlo remoto do
Claude Code: lanço tarefas e leio o resultado no ecrã do guiador. Nasceu de
uma piada e ficou a funcionar.
Feito com: Garmin, TypeScript, agentes.

## Conversa → backlog

Um bot que lê a conversa de uma comunidade, percebe o que são pedidos reais
e escreve issues limpas, com contexto e prioridade. Menos "alguém tinha dito
isto no Discord".
Feito com: modelos de linguagem, Python, automação.

## Este site

Um sistema operativo em cerca de 100 KB. Astro para o conteúdo, JavaScript
escrito à mão para as janelas, a Dock, os gestos e o telefone dentro do
telefone. Sem React, sem bibliotecas de animação, sem tracking.
Feito com: Astro, CSS, sem frameworks.

Quase tudo isto está em https://github.com/helderpgoncalves
