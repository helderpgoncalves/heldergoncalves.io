For years, everything I learned ended up in places that are not mine: Slack messages nobody reads twice, pull request comments, threads that quietly disappear. This is my attempt to fix that.

## What you will find here

Short notes on what I am building. A lot of software with language models inside it — agents, MCP servers, automation — but also the boring parts: deploys, containers, the bug that took three days and turned out to be an environment variable.

I write first for myself six months from now, when I no longer remember how I solved the thing. If it helps someone else, even better.

## How it works

No newsletter, no popup, no cookies, no trackers. There is an [RSS feed](/en/rss.xml) and that is it. I publish when there is something worth saying — there is no schedule.

Almost everything I mention is open source on [GitHub](https://github.com/helderpgoncalves). If you disagree with something, write to me: the address is on the home page, and I answer anything that comes with context.
